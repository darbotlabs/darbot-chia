# Darbot Chia Assets

This directory contains all assets for the Darbot Chia project components.

## Provided Assets

All required assets have been provided in GitHub comment #2926275214 and should be downloaded and placed in the appropriate subdirectories.

## Directory Structure

- `marketing/` - GitHub social preview and VSCode marketplace banner
- `brand/` - Brand guidelines and style documentation

## Related Asset Directories

- `vscode-extension/assets/` - VSCode extension icons and status indicators
- `npm-package/assets/` - NPM package logo and badge

## Installation

See the README.md files in each subdirectory for specific installation instructions and asset mapping from the GitHub comment.
