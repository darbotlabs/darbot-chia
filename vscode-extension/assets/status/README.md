# Status Icons

This directory contains status indicator icons for the Darbot Chia VSCode extension.

## Asset Sources

These assets should be downloaded from GitHub comment #2926275214:

- `connected.png` - from `leaf_32_connected.png`
- `disconnected.png` - from `leaf_32_disconnected.png`  
- `syncing.png` - from `leaf_32_syncing.png`

All icons are 32x32 pixels and will be used in the status bar to indicate connection state.
